Настройки

Самый простой способ включить ИИ: aistudio.google.com/apikey → «Create API key» → скопировать и вставить сюда. У Google есть бесплатный лимит; если он кончится, приложение скажет об этом и продолжит писать без ИИ.

Есть платный ключ Claude API

Правит заметно лучше, но платно: console.anthropic.com → API Keys. Если заполнены оба ключа, используется этот.

Ключи хранятся только в этом браузере и уходят только на сервер того сервиса, чей ключ введён.
